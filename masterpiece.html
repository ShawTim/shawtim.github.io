04 — Judgement in the LoopCaught in review — fixed in writing

AI generates most of the code. The work that matters is catching what it gets wrong — and knowing why.

werewolf/agent-loop.tsReview log #01

// Agent generated — race condition

async function runNightCycle(agents) {
  await Promise.all(agents.map(a => act(a)));
  // resolveDeaths reads state mid-flight
  resolveDeaths(gameState);  // ← state not yet settled
}

// Human intervention — serialise the critical section

async function runNightCycle(agents) {
  // agents must commit before resolution reads state
  for (const a of agents) {
    await act(a);  // deterministic order, inspectable per-step
  }
  resolveDeaths(gameState);  // ← state fully settled
}

Why: Promise.all let agents race on shared game state — suggested for "performance". Social deduction needs a strict night order so votes stay auditable. Parallelism here breaks replayability, and trust in the sim.

Verdict — serialised: shipped, replayable, auditable
